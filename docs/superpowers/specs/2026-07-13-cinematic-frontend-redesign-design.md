# AI 漫剧平台「电影剪辑室」前端重设计

## 背景与目标

现有应用功能完整，但工作区固定侧栏、依赖悬停的操作、原生 `prompt/confirm`、表单标签关联不足和模态焦点管理缺失，导致平板、键盘和触屏体验不稳定。生产构建还包含约 1 MB 全语言字体资源，首屏加载与离线启动也有可感知的等待。

本次重设计以用户选择的「电影剪辑室」方向为准，目标是让“项目列表 → 选择剧集 → 剧本 → 资产 → 导演台 → 导出 → 提示词”成为一条一致、清晰、可通过键盘和触屏完成的创作流程。

## 已确认的产品决策

- 操作体验优先，视觉与性能改动服务于核心工作流。
- 桌面与平板（视口宽度不小于 768px）完整可用；更窄视口展示明确的设备提示，不提供完整手机工作流。
- 采用「电影剪辑室」视觉语言：深石墨背景、暖金强调色、媒体画布优先、克制的高密度信息。
- 深色主题为默认主题，同时提供完整浅色主题。
- 采用「稳定骨架，阶段自适应」布局：全局导航和剧集上下文稳定，检查器、时间线和内容结构随阶段变化。
- 保留所有现有业务能力、IndexedDB/OPFS 数据和路由，不改后端协议。

## 信息架构与页面骨架

### 应用级骨架

- 登录页保持独立沉浸式入口，不显示应用导航。
- 其他页面使用窄型全局导航轨道，提供项目、登录状态、语言、主题和设置入口。
- 主内容区域独立滚动，避免全页与阶段内容出现竞争滚动。
- 视口小于 768px 时只渲染设备提示和返回说明，避免把不可操作的密集工作区压缩到手机宽度。

### Dashboard

- 顶部展示当前创作空间、主要动作和配置状态；项目网格作为主内容。
- 项目卡改为语义化可聚焦入口，重命名、复制、导出和删除操作在触屏与键盘下始终可达。
- 创建、导入和示例项目入口支持换行，768px 宽度不产生横向溢出。

### Workspace

- 桌面端左侧固定剧集导航；平板端折叠为可关闭抽屉。
- 顶部保留项目/剧集上下文和五阶段导航；阶段导航可横向滚动并具备选中语义。
- 中央内容根据阶段自适应：剧本使用宽编辑面，资产使用媒体网格，导演台强化画面与镜头序列，导出强化排序与时间线，提示词使用可复制的编辑列表。
- 核心操作不再只依赖悬停或双击；每个剧集和项目均有明确的操作按钮。

## 视觉系统

- 深色主题以近黑石墨、冷灰表面和暖金强调色组成；浅色主题使用暖白纸面、石墨文字和同一暖金语义色。
- 重新定义背景、表面、边框、文字、强调、成功、警告和危险色，保证普通文字达到 WCAG AA 对比度。
- 圆角、阴影和描边更克制，强调媒体与信息层级，不使用全局类名模糊匹配产生悬停位移。
- 正文使用 Inter 拉丁子集并回退到系统中文字体；镜头编号和时间码使用 JetBrains Mono 拉丁子集。
- 所有动效尊重 `prefers-reduced-motion`。

## 组件与交互边界

### 基础组件

- `Button`、`IconButton`、`Input`、`Textarea`、`Select`、`Card`、`Badge` 使用统一焦点环、禁用态、加载态和尺寸规则。
- `Label` 支持 `htmlFor`，所有表单控件通过 `id` 建立程序化关联。
- `Modal` 支持标题关联、Escape 关闭、初始聚焦、焦点圈定、关闭后焦点恢复和背景点击关闭。
- 全局对话框服务提供异步 `confirm` 与 `prompt`，替换核心流程中的浏览器原生弹窗，统一危险操作和文本输入体验。

### 反馈与状态

- Toast 容器使用 `aria-live`，错误与成功状态具备可读的颜色和文本。
- 生成中按钮保留原标签语义并暴露忙碌状态。
- 空状态、加载状态和失败状态都在当前工作上下文内显示，不用空白页替代。

## 数据流与稳定性

- 业务 Context 和持久化模型保持不变，组件改造不改变项目数据格式。
- Auth 启动先恢复本地状态并解除全屏初始化，再在后台校验远端会话；不可达网关不得阻塞本地编辑。
- 阶段组件按需加载；JSZip 仅在执行导出时动态加载。
- 字体限定实际子集，生产构建不发布含源码内容的 sourcemap。

## 错误处理

- 导入失败、远端认证失败和生成失败使用统一可访问反馈，不吞掉错误。
- 自定义确认对话框明确展示目标对象和危险语义；取消不会触发数据修改。
- 平板抽屉、模态和菜单均支持 Escape 关闭并恢复触发元素焦点。

## 测试与验收

- TypeScript 严格检查、现有 18 个 service 测试和生产构建必须继续通过。
- 增加无需浏览器依赖的组件服务端渲染测试，覆盖按钮忙碌语义、表单标签关联、状态徽标和移动端阻断提示。
- 768px 宽度下 Dashboard、Workspace 五阶段和 Settings 不出现页面级横向溢出；左侧剧集导航可通过抽屉访问。
- 项目卡、剧集、阶段导航、对话框和主要按钮均可通过键盘操作，触屏不依赖 hover。
- 深浅主题中的普通文字与主要按钮达到 WCAG AA 对比度；减少动效偏好生效。
- 构建产物不再包含非拉丁字体子集，JSZip 不进入首屏预加载链，生产 sourcemap 不输出。

## 非目标

- 不重写 IndexedDB/OPFS 数据层、AI 适配器或后端接口。
- 不实现小于 768px 的完整手机创作工作流。
- 不新增命令面板、拖拽编辑器、协作、云同步或其他未要求功能。
- 不执行 Git 分支、提交或推送。
